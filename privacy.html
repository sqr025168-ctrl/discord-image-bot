سياسة الخصوصية – SAQR Image Bot

آخر تحديث: 25 أغسطس 2026

تحترم SAQR Image Bot خصوصية المستخدمين. توضح هذه السياسة كيفية التعامل مع المعلومات عند استخدام التطبيق.

استخدام Pinterest

قد يستخدم SAQR Image Bot واجهة Pinterest API للوصول إلى محتوى وصور Pinterest المسموح بالوصول إليها من خلال واجهة البرمجة، بهدف عرض محتوى الصور داخل Discord.

البيانات

لا يقوم SAQR Image Bot ببيع المعلومات الشخصية للمستخدمين. ولا يتم استخدام البيانات التي يتم الوصول إليها لأغراض إعلانية.

Discord

قد يتعامل التطبيق مع معلومات تقنية ضرورية لتشغيل البوت داخل خوادم وقنوات Discord وتنفيذ وظائفه.

التغييرات على هذه السياسة

قد يتم تحديث سياسة الخصوصية عند إضافة ميزات جديدة أو تغيير طريقة عمل التطبيق.

التواصل

للاستفسارات المتعلقة بالخصوصية، يمكن التواصل مع مشغل SAQR Image Bot.
